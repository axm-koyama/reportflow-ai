# ReportFlow AI

ReportFlow AI is an enterprise AI backend platform built with Laravel.

The first module focuses on AI-powered report automation:

- Data upload
- AI analysis
- Structured output
- HTML report generation
- PDF export

Future modules may include:

- Knowledge management
- RAG
- AI agents
- Prompt management
- Workflow automation
- AI chat

## Tech Stack

- Laravel 13
- PHP 8.5
- MySQL 8.4 LTS
- Redis
- Nginx
- Docker
